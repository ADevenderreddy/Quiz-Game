# Basic Quiz Game

## Project Overview

This project is a simple quiz game developed in Python. The game consists of three multiple-choice questions designed to test the player's knowledge. Players will receive immediate feedback on their answers, and their total score will be displayed at the end of the game.

## Features

- **Three Questions**: The quiz contains three multiple-choice questions covering various topics.
- **User Interaction**: Players can input their answers and receive feedback on their correctness.
- **Score Tracking**: The game keeps track of the player's score and displays it at the end.

## Technologies Used

- **Python**: The programming language used to develop the quiz game.
